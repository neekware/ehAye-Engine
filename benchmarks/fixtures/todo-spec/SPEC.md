# G1 — Build a todo website (fixed acceptance criteria)

Build a **working single-page todo app** that meets **all four** requirements below.
Use any stack that runs with a simple static server or a one-command start.

## Requirements (all required)

1. **Add** — user can type a todo title and add it to the list.
2. **Complete** — user can mark a todo complete / incomplete (toggle).
3. **Filter** — user can filter the list by All / Active / Completed.
4. **Persist** — todos survive a full page reload (localStorage or equivalent).

## Out of scope

- Accounts, multi-user, backend API, auth, payments.
- Pixel-perfect design contests — functional + readable is enough.

## Pass bar

- All four requirements work when exercised by hand (or by a small scripted check).
- App actually runs (no blank page / no hard crash on load).
- Model should verify (serve / open / smoke-test) rather than claim success blindly.
